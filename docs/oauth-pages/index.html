Pi Photo Booth

A personal Raspberry Pi desk display.

This is a hobby project running on a single Raspberry Pi on my desk. It shows what I'm currently playing on Spotify, cycles through my own photos when the music is paused, and has a camera mode that takes pictures with an attached webcam.

Why it asks for Google Drive access

When I take a picture with the device, it saves the photo to the Pi and also uploads a copy to a folder in my own Google Drive, so the pictures aren't stranded on an SD card.

It requests one scope only:

https://www.googleapis.com/auth/drive.file

That scope is deliberately the narrowest one that can do the job. It only grants access to files the application itself creates. It cannot read, list, modify or delete anything else in the Drive account.

Who it's for

Me. It isn't distributed, sold, or offered to other users, and it has no accounts, no server and no backend.

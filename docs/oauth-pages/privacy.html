Privacy Policy

Pi Photo Booth · last updated 14 September 2026

Pi Photo Booth is a personal hobby application running on a single Raspberry Pi owned and operated by one person. It has no server, no database, no user accounts and no analytics.

What it accesses

The application requests a single Google scope, https://www.googleapis.com/auth/drive.file, which grants access only to files the application itself creates. It cannot read, list, modify or delete any other file in the Google Drive account.

What it does with it

Photographs taken on the device are saved locally to the Pi and uploaded to a single folder in the Drive account of the person who authorised it. That is the only use.

What it does not do

  • It does not read existing Drive files or folders.
  • It does not send data to any third party.
  • It does not collect analytics, telemetry or usage data.
  • It does not share, sell or transfer data to anyone.
  • It does not use Google user data to train any model.

Storage and retention

Photos remain on the Pi's SD card and in the owner's own Drive folder until the owner deletes them. The OAuth refresh token is stored on the Pi's local filesystem with owner-only file permissions and is never transmitted anywhere except to Google's own token endpoint.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions, which immediately invalidates the stored token.
